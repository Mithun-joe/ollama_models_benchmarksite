KV Cache & Hardware Sizing Guide

Total VRAM = Q4 Model Weights + KV Cache

A model's Q4 download size only accounts for static weights. At runtime, Ollama allocates additional VRAM for the KV cache: typically 2–6 GB at short context lengths, scaling up to 10+ GB at 64K context for standard full-attention architectures. By contrast, hybrid linear-attention models such as qwen3.8:27b keep memory growth dramatically lower—requiring only ~4.3 GB KV cache at 64K context.

Verify 100% GPU Offload

After loading a model, check the PROCESSOR column to confirm 100% GPU (no slow CPU/RAM spill):

ollama ps
